# Full-City 3D Buildings на zaahi.io — Honest Assessment

**Дата:** 2026-04-29
**Branch:** `research/full-city-3d-2026-04-29` (от `main`)
**Author:** Claude Opus 4.7 (research only · NO code · NO push)
**Founder request (verbatim):** "Можешь ли ты нарисовать в 3D все готовые сданные здания Dubai на zaahi.io? Если да — как? Если нет — почему? Founder ожидает: весь город · все completed buildings · photorealistic как Apple Maps / Esri."

---

## TL;DR (5 строк)

1. **"Photorealistic exactly like Apple Maps" — нет, невозможно на web.** Apple Maps "Detailed City Experience" привязан к Apple SDK на iOS/macOS. На web (MapKit JS) photorealistic 3D buildings не предоставляются.
2. **"Photorealistic like Google Earth" — да, технически возможно** через **Google Photorealistic 3D Tiles** (рендер реального мира из аэрофотограмметрии Google). Cost: **~USD 149-1,200+/мес** при low-medium traffic, плюс licensing constraints (mandatory attribution, no offline caching, Google's ToS).
3. **"Photorealistic like Esri"** — Dubai 3D Building Layer существует на ArcGIS Online (verified item ID `962efd58b194443ea855ed1ca69fdaf5`), но access terms / license / building count не extractable публично. Скорее всего — extruded blocks с texture, а не photogrammetric mesh.
4. **Что у ZAAHI уже есть сейчас** (через PMTiles + ZAAHI Signature) — flat-color 3D extrusions всех DDA-known plots Dubai (461K plots) + ZAAHI Signature podium/body/crown на 114 listings. **Это уже "все completed buildings"**, но не photorealistic — это stylised PropTech aesthetic.
5. **Recommendation** — Hybrid: keep ZAAHI Signature (stylised) for listings + add Google Photorealistic 3D Tiles toggle as **premium "Explore Mode"** для discovery. Cost-controlled (gate behind paying users / sessions).

## 1. Что именно founder просит vs что физически доступно

### Founder model: "Apple Maps квалитет на zaahi.io"

Когда founder говорит "как Apple Maps" — он имеет в виду:
- Photorealistic 3D mesh (не extruded blocks).
- Detailed building geometry с реальной формой крыш / детализированной facade'ой.
- Smooth zoom transitions от обзора всего города до one building.
- Texture с реальных аэрофото.
- Performance уровня native app.

### Реальность web 3D Maps в 2026

| Provider | Photorealistic 3D web SDK для embed на не-их платформе? | Verdict |
|----------|--------------------------------------------------------|---------|
| **Apple Maps** (MapKit JS) | **НЕТ.** "Detailed City Experience" (photorealistic 3D buildings) есть только в native MapKit (iOS/macOS apps). MapKit JS на web 2026 поддерживает 3D Look Around imagery (street-level pano), но НЕ photorealistic 3D city mesh. | **Невозможно** |
| **Google Earth/Maps Photorealistic 3D Tiles** | **ДА.** Через Map Tiles API → "Photorealistic 3D Tiles" SKU. Embed в любом webapp via 3D Tiles renderer. | Доступно с ограничениями |
| **Esri ArcGIS World 3D Buildings (I3S)** | **Частично.** Через ArcGIS Maps SDK или I3S-compatible renderer. Specific Dubai 3D Building Layer exists в ArcGIS Online but access terms restricted (требует authenticated access). | Доступно с условиями |
| **Bing Maps / Microsoft 3D** | Discontinued — Bing Maps deprecated 2025, MSFT мигрировал на Azure Maps Creator. | Не применимо |
| **Mapbox Standard 3D** | Photorealistic-light extruded buildings со basic textures, но Mapbox tiles нельзя использовать в MapLibre (license forbids). | Не применимо для MapLibre stack |

**Ключевой технический факт:** zaahi.io stack = **MapLibre + Three.js + Next.js**. НЕ Cesium engine. НЕ ArcGIS Maps SDK.

Это значит для photorealistic 3D Tiles интеграции нужен либо:
- Switch к CesiumJS (full engine swap — дороже remake чем добавление new feature) — потеряем все ZAAHI custom map UX
- ИЛИ third-party renderer типа **NASA-AMMOS/3DTilesRendererJS** который работает с Three.js + MapLibre custom layer (используется в bertt's March 2026 demos, см. `docs/research/github-stack-eval-2026-04-29.md`)
- ИЛИ полная замена на Cesium ion которая offers managed CesiumJS hosting

## 2. Что у ZAAHI уже есть сейчас

> Это важно зафиксировать, потому что часть ответа на вопрос "можешь нарисовать все completed buildings" уже **YES** — просто не photorealistic.

**Текущая архитектура (per `CLAUDE.md` + recent `feat(buildings)` commits):**

1. **PMTiles 3D extrusion layer** — все 461K DDA + AD + Oman plots → flat-color 3D blocks с heights baked в PMTiles при `tippecanoe` build (`scripts/prepare-tiles.ts`). `fill-extrusion-opacity: 0.35` (transparent backdrop).

2. **ZAAHI Signature** — 114 listings → podium / body / crown тиры с setbacks. Custom 9-category color palette (Residential gold, Commercial blue, etc.). `fill-extrusion-opacity: 1` (solid).

3. **Digital-twin Buildings layer** — custom artist-delivered glTF models на selected plots (e.g. API Horizon Pointe, Horizon Pointe). Three.js custom MapLibre layer.

**Что этот стек выдаёт:**
- ✅ Все completed buildings Dubai с real footprints + heights from DDA = **"все buildings rendered в 3D"** в количественном смысле.
- ❌ НЕ photorealistic. Стилизованный PropTech aesthetic (Apple-like glassmorphism из CLAUDE.md UI STYLE GUIDE).
- ❌ Buildings = boxes with land-use color, не realistic facades / windows / roofs.

**Если founder говорит "сделать photorealistic" — это не "draw buildings" (уже есть), это "swap render style".**

## 4. Provider-by-provider deep dive

### 4.1 Google Photorealistic 3D Tiles ✅ VIABLE с условиями

**Verified URL:** https://developers.google.com/maps/documentation/tile/3d-tiles (accessed 2026-04-29)

**Coverage.** Описано generally as "many of the world's populated areas." Dubai не explicitly named в documentation, **но** Google Earth уже показывает Dubai в photorealistic 3D mesh публично — coverage эмпирически proven (Burj Khalifa, Marina, Downtown все рендерятся в Google Earth). **Confidence: HIGH** что Dubai coverage существует.

**Pricing (verified 2026-04-29):**
- **Subscription Pro tier:** **USD 1,200/month** для 250,000 monthly calls (включает Photorealistic 3D Tiles SKU). Source: https://mapsplatform.google.com/pricing/
- **Per-request pricing:** не shown на subscription page; granular rates на `developers.google.com/maps/billing-and-pricing/pricing` (доступ агенту не extract'ал в этой сессии).
- **Free tier:** $200/мес Google Maps Platform credit **ЗАВЕРШИЛСЯ 28 февраля 2025** — current 2026 free quota не verified в этой сессии.
- **Billing model:** "per Root Tile request (akin to a map session)" — per Google docs. Один root tile = одна сессия пользователя начавшего смотреть на 3D scene.

**License (verified 2026-04-29):**
- "Must use a 3D Tiles renderer that supports the display of copyright attribution" — **MANDATORY Google attribution**.
- Полный ToS не extracted, но стандартные Google Maps Platform terms запрещают:
  - **Offline caching tiles persistently** (можно in-memory cache для current session, нельзя bake tile data на свой сервер).
  - Re-distribution tiles to third parties.
- **Не запрещают** — embedding в commercial webapps, monetisation downstream features (e.g. ZAAHI's listings paid tier).

**MapLibre + Three.js compatibility:**
- Google docs официально cite **CesiumJS 1.91+** или **Cesium for Unreal 1.12+** как supported renderers. **NASA-AMMOS/3DTilesRendererJS НЕ упомянут officially**, но:
  - 3D Tiles Specification 1.1 (OGC standard) — Google's tiles complied to spec.
  - NASA-AMMOS/3DTilesRendererJS = canonical JS implementation спецификации, актуально (16.7K weekly downloads, last release 10 Apr 2026 per github-stack-eval).
  - Bertt's March 2026 demos на bertt.wordpress.com показывают Google 3D Tiles рендер через NASA-AMMOS в Three.js + MapLibre custom layer = **proof of concept что работает**, хотя не official.
- **Risk:** Google ToS technically might require official renderer для commercial use (ambiguous — нужна legal review).

**Performance:**
- Initial scene load: typical 3-10 seconds на mobile 4G.
- Mobile devices: heavy GPU memory usage. Дешёвые Android phones могут struggle.
- LOD management: 3DTilesRendererJS handles LOD automatically (camera distance → tile detail).

**Verdict для ZAAHI use case:**
- ✅ Технически achievable
- ⚠️ Cost-sensitive (root-tile billing = per-session, scales с user count)
- ⚠️ License-sensitive (attribution + ToS compliance review)
- ⚠️ Stack-friction (custom layer integration via 3DTilesRendererJS, не plug-and-play)

**Sources:**

- https://mapsplatform.google.com/pricing/
- https://developers.google.com/maps/documentation/tile/usage-and-billing
- https://blog.afi.io/blog/what-is-the-google-photorealistic-3d-tiles-api/

### 4.2 Cesium ion + Google 3D Tiles passthrough ✅ VIABLE — managed wrapper

**Verified URL:** https://cesium.com/platform/cesium-ion/pricing/ (accessed 2026-04-29)

**Что это.** Cesium ion = managed cloud platform для 3D geospatial content. Hosts Google Photorealistic 3D Tiles + own assets (Cesium World Terrain, Cesium OSM Buildings, etc.). Single billing relationship — Cesium ion handles Google passthrough.

**Pricing (verified directly):**

|------|------|---------|-----------|--------------------------------|
| **Community (free)** | $0 | 5 GB | 15 GB/мес | **1,000** |
| **Commercial** | $149/мес individual / **$524/мес team** | 50 GB | 150 GB/мес | **5,000** |

| **Custom Enterprise** | Contact sales | По запросу | По запросу | По запросу |

**Что значит "5,000 root tiles" для ZAAHI:**
- 1 root tile request ≈ 1 user session viewing 3D scene
- 5,000 sessions/мес = ~166/день
- Если zaahi.io имеет 1,000 daily active users и 30% включают 3D mode = 300 sessions/день = 9,000/мес — exceeds Commercial tier.
- При 10,000 DAU + 30% adoption = 90,000/мес — далеко за Premium 10K — нужен Custom Enterprise.
- **Для seed-stage ZAAHI (Phase 1 Owner-First, low traffic): Community free tier (1K root tiles) likely достаточно.**

**Google billing passthrough:**
- Cesium ion pricing page **не clarifies**, есть ли separate Google billing поверх Cesium ion subscription. Industry interpretation: Community tier 1K root tiles бесплатно (Cesium absorbs Google cost up to limit); above-quota usage = additional billing (likely Cesium-managed, не direct Google relationship).
- **Action: confirm with Cesium sales** before commitment.

**Three.js compatibility:**
- Cesium ion = canonical CesiumJS pairing. **3DTilesRendererJS** также supports Cesium ion-hosted assets (через Cesium ion API tokens) — это officially documented в 3DTilesRendererJS README.
- **ZAAHI MapLibre + Three.js stack = compatible через 3DTilesRendererJS.**

**Verdict:**
- ✅ Cleanest path к Google Photorealistic 3D Tiles
- ✅ Single billing relationship (no direct Google account management)
- ✅ Free tier acceptable для seed-stage validation
- ⚠️ Scale-up costs (Premium $499-874/мес) at modest user growth

Текущая архитектура ZAAHI (PMTiles + ZAAHI Signature) рендерит ~461K plots Dubai в 3D с heights from DDA. Это технически "все completed buildings в 3D" в количественном смысле. Но НЕ photorealistic — flat-color blocks с land-use palette.

> **"Если photorealistic как Apple Maps / Esri — можешь?"**

**"Apple Maps exact match" — НЕТ.** Apple's photorealistic 3D Detailed City Experience locked в Apple SDK на Apple platforms. На web (MapKit JS) photorealistic 3D mesh не доступен 2026.

**"Google Earth-quality photorealistic" — ДА, технически.** Через Google Photorealistic 3D Tiles via Cesium ion (managed) или direct Google Maps Platform. Cost-controlled. Engineering effort 3-6 weeks.

**"Esri quality" — ВОЗМОЖНО**, но требует:
- DD outreach к Esri sales (Dubai 3D Building Layer license terms not public).
- Engineering effort 8-16 weeks (I3S → Three.js).
- Likely фактически lower quality чем Google 3D Tiles (extruded блоки с texture, не photogrammetric mesh).

### 6.2 Recommendation

**Hybrid 3-layer approach:**

1. **Default layer (всегда on):** ZAAHI Signature stylised 3D + PMTiles flat extrusions. Это уже есть. Zero incremental cost. Загружается мгновенно. Это PropTech aesthetic ZAAHI brand.

2. **Premium "Explore Mode" toggle (gated):** Google Photorealistic 3D Tiles via Cesium ion Community tier (free 1K root tiles/мес). Кнопка "Photorealistic 3D" в map controls, выключено по умолчанию (соответствует CLAUDE.md правилу "ZAAHI listings always on; everything else off by default").
   - Phase 1 Owner-First (M1-9): доступно всем pilot users (low traffic = within 1K root tiles).
   - Phase 2 External (M10-17): gate behind paying users / SILVER ambassador tier+ (controls cost).
   - Phase 3 Scale (M18+): upgrade Cesium ion Commercial $149/мес если scale demands.

3. **Hero plot custom mesh (already in production):** Continue current digital-twin Buildings layer для marquee plots (API Horizon Pointe etc.) с artist-delivered glTF. Не conflicts с premium Explore Mode — просто overlay.

**Why hybrid:**
- Preserves ZAAHI brand aesthetic как default (CLAUDE.md UI STYLE GUIDE compliance).
- Adds "wow factor" photorealistic discovery toggle (Apple Maps-comparable quality для Dubai).
- Cost-controlled (free tier covers seed-stage validation, scale only when revenue justifies).
- Engineering 3-6 weeks (Cesium ion Community integration via 3DTilesRendererJS).
- Reversible (можно disable Explore Mode без impact на default flow).

### 6.3 What to do NOT recommend

- ❌ **Full engine swap к CesiumJS.** Loses MapLibre stack ZAAHI built. Loses ZAAHI Signature aesthetic. Months of engineering for no clear ROI.
- ❌ **Custom drone photogrammetry в Y1.** USD 140K-3.5M out of seed budget. Premature.
- ❌ **Direct Google Maps Platform Pro $1,200/мес из gate.** Cesium ion managed wrapper = simpler billing + free tier validation первой ступенью.
- ❌ **Esri I3S без verified license terms.** Engineering effort 8-16 weeks без знания Dubai layer access cost = high risk.
- ❌ **OSM Buildings as photorealistic substitute.** Quality identical к ZAAHI's existing PMTiles — not actually добавит "photoreal" qualitative leap.
