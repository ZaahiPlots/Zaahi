## КЛЮЧЕВЫЕ ВЫВОДЫ MESHY-ПИЛОТА

- **Meshy не справляется с open-frame crown structures** (Boulevard X-frame
  потерян 2 раза подряд). Для таких зданий — procedural Blender build или
  iPhone Scaniverse.
- **Aerial-only набор фото = top-down bias модели** (v1 Boulevard).
  Mix ground + aerial лучше всего; ground-only с building dominant в
  кадре = best (Address Downtown).
- **Decimate Collapse @ ratio 0.18 + UV-delimit** даёт 80% reduction
  poly count с приемлемой потерей качества для z14+ просмотра карты.
- **Non-uniform scale ratio &gt; 2× между осями** = заметное искажение
  текстуры (Boulevard vertical stretch 195× при horiz 26×). Address
  Downtown лучше (161 vs 82/91, ratio &lt; 2×).
- **`target_formats` / `topology=quad` v1 params Meshy игнорит** —
  всегда GLB triangulated по факту.
